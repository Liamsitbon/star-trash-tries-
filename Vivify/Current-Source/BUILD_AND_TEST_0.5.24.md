# Build and test Vivify Quest 0.5.24

```bash
qpm restore
qpm s qmod
```

After installation, confirm the first line of the fresh log is:

```text
=== Vivify 0.5.24 session log ===
```

Test in this order:

1. Murder Plot -> exit to menu -> select and launch another song.
2. 42 Flux through the eclipse/Bloom scene.
3. 42 Flux through NotesCam, Tile, TV, and depth-camera scenes.
4. Practice-mode late start and backward seek.

Keep **Multiview safety**, **Blit effects**, and **Secondary/depth cameras** enabled for the first pass.
